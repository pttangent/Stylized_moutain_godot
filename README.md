# Universal scene-art workflow (generalized branch)

The reusable Blender-first scene-production workflow lives under [canyon-rpg/](canyon-rpg/README.md). The folder name reflects a historical project and **does not restrict the generic workflow to one scene category**.

Core docs: [Universal workflow](canyon-rpg/docs/UNIVERSAL_WORKFLOW.md) · [Scene profile template](canyon-rpg/docs/SCENE_PROFILE_TEMPLATE.md) · [Optional scene-type examples](canyon-rpg/docs/SCENE_TYPE_EXAMPLES.md) · [Modeling guide](canyon-rpg/docs/ENVIRONMENT_ART_MODELING_GUIDE.md).

Canonical bilingual prompts: [Traditional Chinese](canyon-rpg/prompts/zh/) and [English](canyon-rpg/prompts/en/). P1-concept uses Blender art grayboxes by default; interactivity is an explicit optional branch. Existing scene-specific data, research transcripts and specialist workflows remain as archival/project-specific material, not generic requirements. This branch does not assert that an actual scene was modeled or rendered.
