# P0-B — 選用的模型輔助藍圖整合

只有在 P0-A 額外檢查過**真實提供的來源模型**後才執行。

核對來源、hash、座標單位、軸向與轉換；將模型的候選表面與已核准的藝術幾何嚴格分層。只整合有證據的特徵，記錄模型／圖片／使用者決策的矛盾，不將未知區補成所謂實測。

按當前場景選擇所需的空間表示、關係與驗證器；無必要時不建立任何特定資料結構。完成通用參考幾何合同的結構驗證，並將模型相關檢查獨立紀錄。模型存在、JSON 合法或匯出成功，都不能宣稱場景視覺、比例或碰撞已通過。

交付模型來源 Manifest、差異紀錄、實際診斷資料及版本化 P0B 結果；沒有模型時仍可使用一般 P0-B。
