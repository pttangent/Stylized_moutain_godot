# P1 — Blender 美術白模與可選 Godot 行走路線

**預設執行 prompts/zh/P1-concept.md。** 先在 Blender 建立真正可編輯的場景白模，優先檢查宏觀地貌、岩壁、河道、瀑布、水池、固定 45° 構圖與左右兩個鏡頭。這個階段不需要碰撞、導航或角色行走，驗收後可直接進 P2。

**只有明確要求 playable，才執行 prompts/zh/P1-playable.md。** 在已核准的 Blender 美術白模上疊加 Godot 的碰撞、步道、橋梁、樓梯與 CharacterBody3D 測試；不能為了能走而抹掉原本漂亮且合理的岩壁／河谷構圖。

舊的 P1 playable-first 提示詞已由兩種獨立模式取代。執行 P1 沒有指定模式時，一律選 P1-concept。

## 局部可重入建模與畫面檢查
預設 P1-concept 新增參考圖到幾何合同、L1 宏觀與 L2 岩壁結構的獨立驗收（L3 植被延後）、穩定 art_id／art_owner／art_revision，以及主／左右三固定鏡頭地標檢查。採用 art_idempotent_geometry.py 做局部 Mesh 替換，不可破壞其他地貌與相機；p1_visual_layout_validator.py 只做數值投影，不代表真實渲染已通過。詳見 docs/ENVIRONMENT_ART_MODELING_GUIDE.md。可行走能力仍只在選取 P1-playable 時才處理。
