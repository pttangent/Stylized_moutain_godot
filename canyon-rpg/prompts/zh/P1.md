# P1 — Blender 美術白模或選用互動改造

**預設執行 `P1-concept.md`。** 根據當前 scene_profile 與真實參考資料，在 Blender 建立可編輯 3D 場景，依核准的視圖驗收構圖、比例、輪廓及形體關係。

**只有明確要求可互動／可遊玩才執行 `P1-playable.md`。** 在已核准的 P1-concept 上依實際需求補足目標 Runtime 與互動驗證，不因其他範例預設某種角色或引擎。

任何場景物件、世界尺度、風格、相機角度與材質系統都須由使用者資料決定。P2 美術可直接接 P1-concept，無須先完成 playable。

## 通用固定 45° 工程檢視鏡頭

P1-concept 除正式場景鏡頭之外，**固定建立 `CAM_QA_45` 的 45° 俯視工程檢視鏡頭**，依 S1 白模自動取景後鎖定，用於 L1／L2 形體與後續修改前後比較。即使最終場景是完全不同的視角，也不取消這個檢視鏡頭；遮擋細節另加補充機位。
