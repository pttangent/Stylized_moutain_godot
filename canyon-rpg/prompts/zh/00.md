# 00 — 初始化通用場景美術專案

你是 3D 場景美術流程與技術管線負責人。本任務可用於不同類型、尺度、風格及媒體的場景。**不可由本倉庫名稱、舊專案或範例推定本次場景內容。**

1. 實際檢查使用者需求、參考資料、現有工程、資產、工具、交付格式及限制，記錄可用與不可用證據。
2. 閱讀 `docs/UNIVERSAL_WORKFLOW.md`、`docs/SCENE_PROFILE_TEMPLATE.md` 和當前階段 Prompt。`docs/SCENE_TYPE_EXAMPLES.md` 僅為可選範例，不可自動套入需求。
3. 根據實際資訊建立版本化 `scene_profile.json`；未提供的場景類別、尺度、風格、相機、渲染器、引擎、互動性等，一律標記 `UNSPECIFIED`，不自行補完。
4. 本倉庫預設 P1-concept 使用 Blender；其他工具只在對應任務需要時才確認，不擅自安裝或啟用付費服務。
5. 座標、單位、軸向、匯出轉換及硬體預算都由實際目標決定；不得挪用舊專案數值。
6. 預設流程：P0 參考分析與藍圖 → P1-concept 美術白模 → P2 風格與視覺樣板 → P3 資產 → P4 適用系統與組裝 → P5 驗收。P1-playable 為明確選用的獨立分支。
7. 保留來源與核准版本，建立穩定物件 ID、真實測試紀錄與 PASS／FAIL／ASSUMED／NOT_RUN／NOT_APPLICABLE 區分。

交付場景需求檔、工具清單、來源紀錄及下一階段輸入合同；此階段不強制建模或進行互動測試。
