# TASK 00 — 初始化美術優先的峽谷環境製作流程

先檢查既有檔案與 Blender／Python（Godot 為後續可用工具），不覆寫來源證據。保持可重跑 Blender Python、可編輯 .blend、獨立 GLB 與實際鏡頭渲染。設計座標採 Godot Y-up，Blender Z-up 轉換需驗證。

預設階段：P0 原圖導向地貌／坡度／水流／構圖藍圖 → **P1-concept Blender 美術白模（預設）** → P2 美術 Lookdev → P3 模組庫 → P4 程序化自然環境 → P5 視覺／引擎 QA。只有明確要求時才選 P1-playable，增加 Godot 可行走、碰撞和導航測試。

新提供的 Tripo 小型 3D 模型僅為可選參考，不是實測地形；不可默默取用舊版不同來源模型。保留來源、版本、實際命令及未完成的驗收。不可未經許可使用付費生成。
