# P5 — Independent visual and technical quality assurance

Run P5-A.md for evidence-backed visual review using the scene's **approved shots and style**. Run P5-B.md for actual production/render/runtime validation that is applicable to the selected deliverables. No scene content, camera angle, material family, target engine, simulation or playable actor is assumed.

All outcomes must distinguish observed PASS/FAIL from NOT_RUN, NOT_APPLICABLE and ASSUMED. Source provenance, revision history, real visual outputs and actionable defects take precedence over plausible-sounding descriptions.
