# P2 — Derive art direction and validate a representative visual slice

P2-A.md defines scene-appropriate style and presentation based only on actual user input and approved visual evidence. P2-B.md implements and compares a **representative subset** of the scene using the approved P1-concept geometry and selected renderer. Neither phase assumes a particular visual style, material family, shot count, runtime engine, procedural system or interactive character.

P1-concept approval is the art prerequisite; P1-playable is optional. Run only the parts and rendering checks that the scene profile actually requires. Report missing data and explicit assumptions instead of filling them from separate scenario examples.
