# P3 — Reusable assets, selectively and without assumed categories

Run P3-A.md to derive the real scene's asset/feature inventory and reuse strategy. Then run P3-B.md to create and test only the approved reusable/unique components. Do not assume any pre-listed family of objects, any geometry style, a runtime engine, physics, a material atlas or a generative model service.

P3 is informed by the approved P1-concept and P2 style/lookdev. It must not change approved layout or cameras without a versioned design revision. P1-playable remains an optional constraint only when selected.
