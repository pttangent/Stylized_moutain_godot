# P1 — Select a Blender Blockout Mode

**DEFAULT: P1-concept.md** — build an actual editable Blender environment-art graybox from P0 and the reference image. Emphasize landscape geomorphology, waterfall tiers, irregular cliffs, convincing pool/riverbank transitions, shape hierarchy, 45-degree hero framing and two fixed alternate shots. Collision, navmesh and character traversal are NOT required. Exit into P2 visual lookdev after art approval.

**OPTIONAL: P1-playable.md** — only when the user explicitly asks to make the **approved P1-concept scene** playable. Preserve its art-directed meshes and framing; add a separate Godot collision/navigation layer, bridges/stairs/paths as required, CharacterBody3D traversal tests, and engine evidence. Do not create a playable scene by silently flattening the art terrain.

Run only one selected mode. If P1 is requested without further qualifiers, execute P1-concept.md. Historical P1 physics-pending statuses concern earlier design checks and must not block art-only P1-concept.

The prior playable-first prompt has been superseded by P1-playable.md. Never treat a navigation graph as an exact route mesh, and never claim a renderer or traversal test ran when only JSON was checked.

The P1-concept default now requires a source-image/reference-to-geometry contract, L1 macro + L2 structural shape gates (L3 dressing deferred), stable per-mesh art_id/art_owner/art_revision and three locked camera anchor checks.
