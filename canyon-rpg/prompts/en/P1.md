## Inputs and gates
Use the supplied reference image and the *approved* P0 scene blueprint, true top-down map, elevation data, water graph, navigation graph, cliff boundaries and camera specification. Inspect existing work before changing files. If P0 is unavailable, say which dependencies are missing; do not invent validated topology.

## Geometry modeling
1. Build editable Blender Python generators for terrain terraces, slopes, cliff walls, cliff caps, riverbeds, waterfall openings, wooden bridges, bridge supports, stairs and walking paths.
2. Preserve agreed X/Z coordinates, Y elevations, stable object IDs and 1 unit = 1 m. Steep or overhanging cliffs require independent meshes rather than only heightmap terrain.
3. Use reusable parameterized geometry. Do not collapse the entire canyon into one uneditable mesh.
4. Save scripts, editable .blend source files and independent Godot-compatible .glb exports.
5. Prefer Blender background execution from CLI; a Blender MCP installation is not required.

## Godot playable implementation
1. Create working upper-canyon, central-waterfall and lower-basin sub-scenes, plus a combined scene.
2. Use temporary color-coded or clay materials, not final textures or vegetation.
3. Add static collision and correctly oriented transforms. Use hidden smooth walking ramps over visible stairs where necessary for a smooth controller.
4. Implement a basic 1.6 m CharacterBody3D test player with walking, gravity and optional jump.
5. Build NavigationRegion3D or equivalent route tests and verify traversability across major bridges, stairs and terraces.
6. Use the approved ~45-degree orthographic RPG camera for a target composition and a separate free engineering camera for geometry QA.

## Tests and review
Run actual Blender geometry export, Godot import, scene parse checks, collision tests, navigation connectivity checks and path traversal. Capture real Godot runtime screenshots at the target aspect ratio. Compare upper falls, main falls, central bridge, lower pool, foreground bridge and cliff tiers against the source reference. Adjust only explainable geometry/composition mismatches.

## Deliverables
- Reproducible Blender generator and editable model sources
- Modular blockout GLBs and Godot .tscn scenes
- Test character and route/collision tests
- Fixed-camera and free-camera actual in-engine screenshots
- reports/P1_blockout.md with performed commands, PASS / FAIL / ASSUMED / NOT RUN, screenshot paths, outstanding issues and commits where available

Stop after a coherent playable blockout. Do not spend model-generation credits or start polished trees, materials and water effects.
